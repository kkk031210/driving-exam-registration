# 驾考考试报名管理系统

## 项目概述

基于 C 语言 + 控制台界面实现的驾考报名管理系统，支持考生信息管理、考试预约管理、科目一/科目四模拟考试功能。

## 功能模块

### 1. 考生管理
- 添加考生信息（姓名、身份证号、联系电话、报考车型、密码）
- 浏览所有考生信息
- 按身份证号/姓名查询考生
- 修改考生信息
- 删除考生信息

### 2. 预约管理
- 预约考试（选择科目、日期、时段、场地）
- 查看所有预约信息
- 按身份证号/预约单号查询预约
- 取消预约（硬删除）
- 更新预约信息（修改时间、场地等）

### 3. 模拟考试
- 科目一模拟考试（100题，随机抽题）
- 科目四模拟考试（50题，随机抽题）
- 自动判分、显示错题解析
- 保存成绩记录

### 4. 角色与登录
- 管理员登录：用户名/密码（默认 `admin` / `admin123`）
- 考生登录：身份证号/密码
- 密码输入隐藏显示（`*` 占位）

## 技术栈

- **语言**：C 语言
- **编译器**：GCC（MinGW）
- **数据存储**：二进制文件（`.dat`）
- **数据结构**：结构体数组 + 计数器

## 数据存储

| 文件 | 说明 |
|------|------|
| `admins.dat` | 管理员账号（首次运行自动创建默认账号） |
| `students.dat` | 考生信息 |
| `appointments.dat` | 预约记录 |
| `venues.dat` | 考试场地（首次运行预置 3 个场地） |
| `questions.dat` | 题库（需手动导入或预置） |
| `scores.dat` | 模拟考试成绩 |
